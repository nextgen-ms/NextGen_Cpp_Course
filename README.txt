NextGen Academy — موقع كورس C++ (عربي + English)
==================================================

الملفات
-------
index.html      الصفحة العربية (RTL) — هي الصفحة الرئيسية
en.html         الصفحة الإنجليزية
css/style.css   التصميم (الألوان والخطوط في أول الملف)
js/config.js    ★ روابط السوشيال ميديا + السعر (عدّل هنا فقط)
js/main.js      التفاعلات
assets/images/  الصور واللوجو

الخطوة الأهم: ضع روابطك
------------------------
افتح js/config.js وبدّل:
  whatsapp     -> https://wa.me/201012345678   (رقمك بالصيغة الدولية بدون + وبدون صفر)
  facebook     -> رابط حسابك على فيسبوك
  telegram     -> https://t.me/اليوزر_نيم
  academyPage  -> رابط صفحة الأكاديمية
  price.amount -> سعر الاشتراك الشهري (لو تركته فاضي هيظهر "تواصل معنا لمعرفة السعر")

التغيير يظهر تلقائيًا في الصفحتين (أزرار الهيرو، الاشتراك، التواصل، الفوتر، وزر واتساب العائم).

التشغيل
-------
افتح index.html في المتصفح مباشرة، أو ارفع الفولدر كما هو على أي استضافة.
الخطوط (Cairo / Inter / JetBrains Mono) بتتحمل من Google Fonts وتحتاج إنترنت.

بعد الرفع
---------
في أول index.html و en.html غيّر og:image إلى الرابط الكامل للصورة
(https://موقعك/assets/images/instructor.webp) لتظهر معاينة جيدة عند المشاركة.

تعديل المحتوى
-------------
النصوص داخل index.html (عربي) و en.html (إنجليزي). تفاصيل مواضيع كل قسم في المنهج
(الشرائح الصغيرة داخل كل قسم) أنا كتبتها كاقتراح، عدّلها حسب شرحك الفعلي.
