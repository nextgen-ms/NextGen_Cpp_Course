01Why this course

Why start programming with C++?

Because it teaches you to think like a programmer: you see how code really runs, you control memory, and you build a base that makes every other language easier.

A strong base for every language

Variables, conditions and functions carry over to any language you learn next.

Logical thinking and problem solving

You practice turning a problem into clear steps before writing code.

A deeper view of memory

With pointers you see how data is stored and how a program reaches it.

A skill in demand

C++ powers games, systems software, competitive programming and anything performance-critical.

Do I need any previous programming experience?
No. The course starts from zero with an introduction to programming basics and logical thinking before you write your first program.
What do I get with each lecture?
A video lesson, a PDF for the lecture, and practice tasks to apply what you learned.
How many lectures do I get each week?
Three lectures every week. At that pace the full course (50 lectures) takes about 17 weeks.
What is the private follow-up?
A private follow-up with a monitor who helps you solve any problem you hit while learning, such as code errors or a concept you didn't understand.
Are there tasks beyond the lecture tasks?
Yes. Besides the task for each lecture, there are weekly tasks and monthly tasks.
